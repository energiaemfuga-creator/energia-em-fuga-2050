O sistema de energia está apresentando falhas. Os quatro laboratórios continuam funcionando, mas o sistema central perdeu parte das informações sobre o caminho da energia em cada tecnologia.

Para restaurar a conexão entre os laboratórios e a rede, analise como a energia é transformada em cada sistema.

☀️ LABORATÓRIO SOLAR

A radiação do Sol é captada por um sistema solar. A energia recebida é convertida em eletricidade. A eletricidade passa pelo inversor e pode ser encaminhada à rede.

Sequência:

RADIAÇÃO SOLAR → CONVERSÃO → ELETRICIDADE → INVERSOR

💧 LABORATÓRIO HIDROGÊNIO

A eletricidade pode ser utilizada para realizar a eletrólise da água. Nesse processo, é produzido hidrogênio, que pode ser armazenado e posteriormente utilizado para fins energéticos.

Sequência:

ELETRICIDADE → ELETRÓLISE → H₂ → ARMAZENAMENTO → USO ENERGÉTICO

☢️ LABORATÓRIO NUCLEAR

Na geração nuclear, a fissão nuclear libera energia na forma de calor. O calor é utilizado para produzir vapor, que movimenta uma turbina. A turbina aciona um gerador, produzindo eletricidade.

Sequência:

FISSÃO NUCLEAR → CALOR → TURBINA → GERADOR → ELETRICIDADE

🌋 LABORATÓRIO GEOTÉRMICO

O calor armazenado no subsolo pode ser utilizado para produzir energia. Esse calor pode alimentar um sistema que movimenta uma turbina, acionando um gerador.

Sequência:

CALOR DO SUBSOLO → TURBINA → GERADOR → ELETRICIDADE
